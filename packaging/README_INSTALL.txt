DESK 0.9.9 - EDIÇÃO PÚBLICA SEM ASSINATURA

Windows 10/11 x64. Inclui Python e as dependências do aplicativo.

Este pacote público NÃO contém credenciais de sinalização/relay. Configure seu
próprio serviço compatível antes de usar a conexão pela internet. Use o exemplo
internet.example.json e as instruções no README do repositório. O arquivo real
internet.json fica ao lado de Desk.exe e não deve ser publicado ou enviado a
quem não deva usar a configuração do seu serviço.

Cada perfil Windows cria sua própria identidade e número fixo. Fechar/reabrir
ou atualizar preserva o número enquanto essa identidade for mantida. O outro
computador precisa ter o Desk aberto e aceitar a sessão. A instalação não ativa
acesso sem supervisão.

Os arquivos atuais não têm assinatura digital. O Windows pode bloquear a
execução segundo sua política. O instalador não altera proteções do Windows.
O projeto está solicitando avaliação da SignPath Foundation; não há aprovação
ou assinatura concedida no momento.

Desinstale em Configurações do Windows > Aplicativos > Desk. Os dados locais de
identidade/favoritos ficam fora da pasta instalada e são preservados.
